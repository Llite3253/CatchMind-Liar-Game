# 📝 프로젝트 소개
##### 사용자들이 실시간으로 그림을 그리며 즐기는 심리 추리 드로잉 게임입니다.
##### 일반적인 캐치 마인드가 단순히 정답을 맞히는 것이라면, 이 게임은 참여자 중 숨어있는 '라이어'를 찾아내는 것이 핵심입니다.
##### 시민은 제시어를 그림으로 표현하여 동료임을 증명해야 하고, 라이어는 제시어를 모른 채 다른 사람의 그림을 유추하여 그럴싸한 그림을 그려 정체를 숨겨야 합니다.

# 🛠️ 사용 기술
+ ##### Spring Boot
+ ##### MySQL
+ ##### HTML/Canvas

# 🚀 주요 기능
+ ##### 1. 게임 로직 및 진행
    + ###### 방 생성 및 입장
    + ###### 게임 시작 시 무작위로 시민과 라이어 역활 부여
    + ###### 정해진 시간 동안 순서대로 캔버스에 그림을 그리는 턴 관리
+ ##### 2. 실시간 인터랙션
    + ###### 실시간 드로잉 동기화 :
        + ###### 사용자가 그리는 선의 좌표 데이터를 실시간으로 전송하여 모든 참여자의 화면에 동일하게 랜더링
    + ###### 게임 진행 중 의사소통 및 추리를 위한 채팅 기
+ ##### 투표 및 결과 처리
    + ###### 게임 종료 후 라이어로 의심되는 플레이어를 투표하는 UI 및 집계 로직
